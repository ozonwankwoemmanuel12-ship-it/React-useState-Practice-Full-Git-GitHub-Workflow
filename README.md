# React useState Practice

A React + Vite practice app demonstrating eight independent `useState` examples: Counter, Light Switch, Step Counter, Multiples List, Star Rating, Password Toggle, Color Picker, and Tab Switcher.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Components

Each component is in `src/components/` and is rendered on the main page in `src/App.jsx`. Each example keeps its state local and demonstrates a different React state interaction.
